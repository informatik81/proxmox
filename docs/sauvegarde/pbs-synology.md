# Configuration des sauvegardes vers un NAS Synology

## Prérequis

- Proxmox Backup Server installé
- NAS Synology accessible sur le réseau

## Étapes de configuration

1. Accédez à l'interface de votre NAS Synology.
2. Créez un dossier partagé pour les sauvegardes.
3. Configurez les permissions d'accès.
4. Connectez Proxmox Backup Server au NAS.

## Configuration sur Proxmox Backup Server

- Ajoutez le NAS Synology comme stockage distant.
- Configurez les paramètres de sauvegarde.

## Vérification

- Testez la connexion.
- Assurez-vous que les sauvegardes sont correctement configurées.

## Conclusion

Vous avez maintenant configuré Proxmox Backup Server pour sauvegarder vers un NAS Synology.
