# Installation de Proxmox Backup Server

## Prérequis

- Un serveur avec Proxmox VE installé
- Accès à Internet

## Étapes d'installation

1. Connectez-vous à votre serveur Proxmox VE.
2. Ouvrez une session SSH.
3. Ajoutez le dépôt Proxmox Backup Server.
4. Mettez à jour les paquets.
5. Installez Proxmox Backup Server.

## Configuration réseau

- Configurez l'adresse IP.
- Assurez-vous que le serveur est accessible depuis le réseau.

## Connexion à un NAS Synology

1. Accédez à l'interface de votre NAS Synology.
2. Créez un dossier partagé pour les sauvegardes.
3. Configurez les permissions d'accès.
4. Connectez Proxmox Backup Server au NAS.

## Vérification

- Testez la connexion.
- Assurez-vous que les sauvegardes sont correctement configurées.

## Conclusion

Vous avez maintenant installé et configuré Proxmox Backup Server pour sauvegarder vers un NAS Synology.
