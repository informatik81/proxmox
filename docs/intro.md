# Introduction

Bienvenue dans la documentation complète de Proxmox VE et Proxmox Backup Server (PBS). Ce site a été conçu pour vous fournir une base de connaissances avancée en français sur ces deux solutions.

Proxmox VE est une plateforme de virtualisation open-source qui permet de gérer des machines virtuelles et des conteneurs. PBS est une solution de sauvegarde qui offre des fonctionnalités avancées pour la protection des données.

## Qu'est-ce que Proxmox VE?

Proxmox Virtual Environment (VE) est une plateforme de virtualisation open source qui combine deux technologies de virtualisation: KVM (Kernel-based Virtual Machine) pour les machines virtuelles et LXC (Linux Containers) pour les conteneurs. Proxmox VE inclut une interface web conviviale pour gérer facilement les VMs, conteneurs, stockage, réseau, et plus encore.

## Qu'est-ce que Proxmox Backup Server?

Proxmox Backup Server (PBS) est une solution de sauvegarde d'entreprise optimisée pour l'environnement Proxmox VE. Il permet de sauvegarder et restaurer des VMs, conteneurs, et même des données physiques avec une déduplication et compression efficaces.
